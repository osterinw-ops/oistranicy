# Политика конфиденциальности приложения «МоиСтраницы»

Дата вступления в силу: 4 ноября 2026 г.

«МоиСтраницы» — приложение для ведения личного списка прочитанных книг. Разработчик: Алексей (osterinw@gmail.com).

## Какие данные собираются

Приложение **не собирает, не передаёт и не продаёт** персональные данные.

- Регистрация и вход не требуются.
- Ваша полка (книги, статусы, оценки, даты) и настройки хранятся **только на вашем устройстве**, во внутренней памяти приложения. При удалении приложения они удаляются.
- В приложении нет рекламы, аналитики и сторонних SDK для отслеживания.

## Сетевые запросы

Для поиска и показа сведений о книгах приложение обращается к открытым каталогам:

- **FantLab** (api.fantlab.ru, fantlab.ru): поисковый запрос и идентификаторы книг и авторов;
- **Google Книги** (www.googleapis.com): поисковый запрос.

При этом сервисам, как и при любом обращении к сайту, становятся известны IP-адрес устройства и технические сведения запроса. Обработка этих данных регулируется политиками самих сервисов. Содержимое вашей полки никуда не отправляется.

## Разрешения

Приложение использует только разрешение на доступ в интернет.

## Дети

Приложение не предназначено для сбора данных детей и не собирает данные пользователей любого возраста.

## Изменения

При изменении политики новая версия публикуется по этому адресу.
