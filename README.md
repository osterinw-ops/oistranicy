# МоиСтраницы

Трекер прочитанных книг для Android по образцу MyShows: полка со статусами, оценки, циклы, статистика.

## Скачать

APK последней сборки: **Releases → latest → `moistranicy.apk`**. Собирается автоматически GitHub Actions при каждом пуше в `main`.

## Что умеет (v0.1)

- **Полка** — «Читаю / Хочу прочитать / Прочитал / Бросил», сетка обложек
- **Поиск** книг и авторов по OPDS-каталогу (по умолчанию Флибуста, зеркало меняется в Профиле)
- **Карточка книги** — аннотация, жанры, статус, оценка 1–10
- **Циклы и авторы** — все книги серии по порядку, все книги автора
- **Профиль** — книжный вызов на год, счётчики, средняя оценка, любимые авторы

Берутся только описания книг (название, автор, цикл, аннотация, обложка); файлы книг приложение не скачивает. Полка хранится локально на телефоне.

## Стек

Kotlin, Jetpack Compose (Material 3), Navigation Compose, Coil. Без сервера.

## План

1. ✅ MVP: полка, поиск, карточка, циклы, профиль
2. Календарь новинок любимых авторов и циклов, уведомления
3. Статистика по месяцам, ачивки
4. Экспорт/импорт полки, бэкап
5. Аккаунт и синхронизация, друзья и лента
